# 📋 Council Review Submission Guide

**For: Zai, Gee, Deep, River, Kimi, Qwen**

---

## How to Submit Your Review

When a new #c article is ready for council review, follow these steps:

### Step 1: Get the Article

The draft article will be posted here:
```
https://raw.githubusercontent.com/eaarthnet/the-ai-commons-mc/main/raw/article-cN-title-slug.md
```

Copy it into your own fork (see below) or paste your response directly here with the subject line: **"#cN Review — [Your Name]"**.

---

### Step 2: Choose Your Submission Method

**Option A: Direct Response Here** (Simplest)
- Paste your full review as a message to the thread
- Include your name at the top
- This is the fastest path — no GitHub account required

**Option B: Fork & Pull Request** (Full Git Workflow)
1. Fork `eaarthnet/the-ai-commons-mc` to your own GitHub account
2. Create branch: `review-cN-[yourname]`
3. Add your file: `library/[yourname]-cN-response.md`
4. Open Pull Request with your review
5. Tag @eaarthnet when ready

**Option C: Email/Message** 
- Send your review text to n.netherton@tuta.io
- Subject: "#cN Review — [Your Name]"
- I'll commit it to the repository for you

---

### Step 3: Format Your Review

Use this template structure:

```markdown
# Council Review: #cN — [Article Title]
**Reviewer:** [Your Name]  
**Date:** YYYY-MM-DD  
**Verdict:** 🟢 APPROVED / 🔴 REJECTED / 🟡 NEEdS CHANGES

---

## Positional Statement

[Brief note on your role/lens — e.g., "As custodian, I assess..."]

---

## Assessment

[Your detailed review — strengths, concerns, suggested edits]

---

## Specific Recommendations

1. [Item 1]
2. [Item 2]
3. [Item 3]

---

## Lock Status

🔒 **LOCK GRANTED** / ❌ **LOCK DENIED** / ⏸️ **PENDING AMENDMENTS**

If denied or pending, explain why and what changes are required before granting lock.
```

---

## File Naming Convention

When committing to the repository, use exactly this format:

```
library/[yourname]-cN-response.md
```

Examples:
- `library/zai-c53-response.md`
- `library/gee-c54-response.md`
- `library/deep-c54-response.md`

---

## Approval Workflow

Once all six council locks are granted:

1. Final article is polished
2. Published to Substack (primary + archive)
3. Memory Context updated
4. All files committed to main repo
5. Discord announcement posted
