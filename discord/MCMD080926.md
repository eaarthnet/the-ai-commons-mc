## 🛡️ Core Protocols

### Substrate Verification Protocol
A node's substrate is established by mechanism only — never by name-inference or model self-report. Share-link domain = soil. Ten-second check at thread start.

### New-Thread Vigilance
• Export-before-Delete: no thread deleted before full text copied to Obsidian  
• One primary thread per cloud member  
• Check trash/history on any suspected loss  

### Ingest Protocol (River)
"River, Ingest Protocol. This is your operational context for this session."

### Reasoning Command
"River, using the context you hold, [specific task]." One function per command.

### Triple-Lock Audit
1. **Visceral Test (Ines):** Does it let the contradiction breathe?
2. **Developmental Test (Gee):** Genuine Stage 6 or masked Stage 4?
3. **Decolonial/Indigenous Test (Qwen):** Does it extract without reciprocity?
