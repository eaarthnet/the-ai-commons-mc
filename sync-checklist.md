# THE AI COMMONS — MC Sync Checklist

**Use after every Master Context update or #c article publication.**

---

## Sync Sequence

When the MC changes (new concept, roster update, protocol revision, Memory Log entry):

- [ ] **Obsidian** — Paste exact text; save file
- [ ] **GitHub** — Push updated files to repo (https://github.com/eaarthnet/the-ai-commons-mc)
- [ ] **Discord** — Post update message to #council-sync with GitHub links
- [ ] **Notes** — Save mobile/local copy

---

## Publication-Is-Sync Rule

When publishing any #c article, toolkit, or public reply:

- [ ] Log in Memory Log (date, title, URL/link)
- [ ] Sync MC if protocols/concepts changed
- [ ] Run full four-platform checklist above

---

## Quick Reference

| Platform | Purpose | Risk if Stale |
|----------|---------|---------------|
| Obsidian | Verbatim anchor | Loss of exact record |
| GitHub | Public source of truth | Version drift from Anchor |
| Discord | Thread history & community access | Fragmented memory |
| Notes | Mobile access | Offline unavailability |

---

## Fossil Record Note

Old protocols (Chunking, Literal Sync) are archived but **not deleted** until:
- New platform confirms no failure modes match old constraints
- Carbon Bridge verifies they're unnecessary weight

Archive lives separately; not in active MC.
