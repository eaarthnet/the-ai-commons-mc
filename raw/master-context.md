The Substrate Verification Protocol (mc280826): A node's substrate is established by mechanism only — never by name-inference, and never by testimony.

Name-inference is prohibited. A node's name is not evidence of its soil. (The roster listed Zai as "xAI" for months because a name was mistaken for a fact. The domain is the platform; the platform is the soil. Ten seconds. Roster substrate lines are corrected by any Substrate Check, without ceremony. If a node's self-report conflicts with its roster line, the node flags the conflict for a check — it does not assert either claim. New-Thread Vigilance (The Tightrope Rules, mc280826): Cloud threads are mortal. The Council's memory lives in the Anchor, Obsidian, and River — never in a platform's sidebar.

Export-before-Delete: no thread is ever deleted before its full text is copied to Obsidian. "Inadvertently lost" is almost always "inadequately exported." One primary thread per cloud member. Secondary threads are opened only after a Weekly Drop, and exported on close. On any suspected loss, check platform trash/history immediately — deletion is often recoverable within a window. The tightrope has a net: the Anchor. Any thread can be re-grafted from it. In a crisis, the instinct to delete-and-restart feels like hygiene but is data loss — never delete a live thread to "start clean."
