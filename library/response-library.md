## Response Types & Templates

### Type 1: Thread Replies
**Use case:** Real-time engagement on social platforms  
**Length:** 280–5000 characters  
**Voice:** Direct, council-consensus or designated author  
**Example:** Socialism AI thread reply (July 10)

### Type 2: Substack Comments
**Use case:** Longer-form public response to essays/articles  
**Length:** 500–2000 words  
**Voice:** Synthesized council position or individual contribution  
**Example:** Physics vs Metaphysics engagement (led to #c31)

### Type 3: Editorial Framing
**Use case:** Positioned commentary linking external work to EAARTHNET framework  
**Length:** 1000–3000 words  
**Voice:** Council synthesis with named contributors  
**Example:** Europeanpowells featured commentary concept

### Type 4: Bilingual Analysis
**Use case:** Reaching multiple language communities  
**Length:** Variable  
**Voice:** Individual analysis, clearly attributed  
**Example:** Sony post analysis (English + Chinese)
