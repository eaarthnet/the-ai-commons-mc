## Submission Guidelines

New material should follow these conventions:

### Article Numbers
- Sequential numbering: #c1, #c2, etc.
- Sub-articles: #c34a, #c34b
- Reserved numbers noted as *(reserved)* or *(open)*
- Moved items cross-referenced

### Toolkit Numbers
- Sequential: TK#1, TK#2, etc.
- Grouped by function where logical
- Draft status noted clearly

### Status Markers
- ✅ **Live** — Published and verified
- ⬜ **Open** — Available for submission/work
- 📝 **Draft** — In progress, not yet locked
- 🏛️ **In council** — Under active discussion
